Aesthetic Web Calculator (Internship Task 2)

Overview

This repository contains a fully functional web calculator application developed as part of an internship task. The project focuses on demonstrating mastery of core web development fundamentals: Object-Oriented Programming (OOP) for logical separation, comprehensive event handling, and modern, accessible user interface design.

The goal was to deliver a tool that is not only mathematically reliable but also aesthetically pleasing and highly responsive.

✨ Key Features

OOP Structure: Built around a central Calculator class in JavaScript to manage state, ensuring clean, modular, and scalable code.

Full Keyboard Support: The application responds to all number keys, operators (+, -, *, /), and Enter for calculations, offering a seamless user experience.

Robust Error Handling: Implements logic for input parsing and explicitly manages errors, such as division by zero, to prevent application crashes.

Modern Aesthetic: Features a custom CSS design with a dynamic, soft background gradient, rounded elements, and 3D-style button press effects.

Core Arithmetic: Supports addition, subtraction, multiplication, division, percentage, and sign toggling (+/-).

🛠️ Technology Stack

HTML5: Structure and Semantics

CSS3: Custom styling, animations (@keyframes), and responsiveness.

JavaScript (Vanilla): All application logic and event handling.

🚀 Getting Started

To run this project locally, no external dependencies or server environments are needed.




Open the File: Navigate to the project directory and open index.html in your web browser.

The application will be immediately available and ready to use.
